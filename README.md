# PHP Programming Learning Project

A beginner-friendly PHP practice project covering core programming concepts through small exercises and a student evaluation example.

## About

This repository is used to practice PHP fundamentals, including:

- Variables and data types
- Arithmetic operations
- Conditional statements
- Grade calculations
- Odd and even number checks
- Basic login-condition examples
- HTML and PHP integration

The learning roadmap is tracked in [PHP Programming Learning Task Checklist.md](PHP%20Programming%20Learning%20Task%20Checklist.md).

## Project Files

- `index.php` - Main PHP practice page containing the current exercises.
- `PHP Programming Learning Task Checklist.md` - Checklist of completed and planned PHP topics.

## Requirements

- PHP 8.0 or later
- XAMPP, or another local PHP server
- A web browser

## Run Locally with XAMPP

1. Install and open XAMPP.
2. Start the **Apache** module.
3. Place this project inside the XAMPP `htdocs` folder.
4. Open the project in a browser:

   ```text
   http://localhost/PHPs/
   ```

## Run with PHP's Built-in Server

From the project directory, run:

```bash
php -S localhost:8000
```

Then visit:

```text
http://localhost:8000
```
