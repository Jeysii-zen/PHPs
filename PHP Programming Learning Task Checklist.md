# PHP Programming Learning Task Checklist

## Phase 1 — PHP Fundamentals

## Phase 2 — Control Structures

- [ ] Practice `switch` statements.
- [ ] Learn `while` and `do-while` loops.
- [ ] Learn `for` loops.
- [ ] Learn `foreach` loops.
- [ ] Practice `break` and `continue`.
- [ ] Create a simple grade calculator.
- [ ] Create a number guessing game.
- [ ] Create a program that determines whether a number is odd or even.

## Phase 3 — Functions and Arrays
- [ ] Learn how to create and call functions.
- [ ] Learn function parameters and return values.
- [ ] Practice default parameters.
- [ ] Learn variable scope.
- [ ] Learn indexed arrays.
- [ ] Learn associative arrays.
- [ ] Learn multidimensional arrays.
- [ ] Practice common array functions.
- [ ] Create a student information management program using arrays.
- [ ] Create a simple shopping cart using arrays.

## Phase 4 — Forms and User Input
- [ ] Learn HTML forms with PHP.
- [ ] Understand the `GET` method.
- [ ] Understand the `POST` method.
- [ ] Learn how to retrieve form data using `$_GET` and `$_POST`.
- [ ] Learn basic input validation.
- [ ] Learn how to sanitize user input.
- [ ] Create a registration form.
- [ ] Create a login form.
- [ ] Create a grade input form that calculates a student's final grade.

## Phase 5 — Object-Oriented PHP
- [ ] Understand classes and objects.
- [ ] Learn properties and methods.
- [ ] Learn constructors.
- [ ] Learn visibility: `public`, `private`, and `protected`.
- [ ] Learn inheritance.
- [ ] Learn method overriding.
- [ ] Learn interfaces and abstract classes.
- [ ] Learn static properties and methods.
- [ ] Convert your student management program into an object-oriented application.

## Phase 6 — PHP and MySQL
- [ ] Install and configure MySQL.
- [ ] Learn basic SQL commands.
- [ ] Create a database using MySQL.
- [ ] Create tables and define primary keys.
- [ ] Learn `INSERT`, `SELECT`, `UPDATE`, and `DELETE`.
- [ ] Connect PHP to MySQL using PDO or MySQLi.
- [ ] Learn prepared statements.
- [ ] Practice inserting form data into a database.
- [ ] Retrieve database records and display them in HTML.
- [ ] Create an edit and delete function.
- [ ] Build a complete CRUD application.

## Phase 7 — Sessions and Authentication
- [ ] Learn PHP sessions.
- [ ] Learn cookies.
- [ ] Create a login/logout system.
- [ ] Store passwords securely using password hashing.
- [ ] Implement `password_hash()` and `password_verify()`.
- [ ] Restrict pages to authenticated users.
- [ ] Create different user roles such as Admin and User.
- [ ] Build an admin dashboard.

## Phase 8 — Intermediate PHP
- [ ] Learn file handling.
- [ ] Learn file uploads.
- [ ] Learn error handling with exceptions.
- [ ] Learn how to organize PHP projects into multiple files.
- [ ] Learn `include` and `require`.
- [ ] Understand namespaces.
- [ ] Learn Composer and dependency management.
- [ ] Learn basic PHP security practices.
- [ ] Learn how to prevent SQL injection.
- [ ] Learn how to prevent XSS and CSRF attacks.

## Phase 9 — APIs and Modern PHP
- [ ] Learn JSON.
- [ ] Learn how PHP works with REST APIs.
- [ ] Create a simple PHP API.
- [ ] Learn HTTP methods: GET, POST, PUT, PATCH, and DELETE.
- [ ] Return JSON responses from PHP.
- [ ] Connect JavaScript to a PHP API using `fetch()`.
- [ ] Build a simple CRUD REST API.
- [ ] Test your API using Postman or a similar tool.

## Phase 10 — Final Projects
Complete these projects in increasing difficulty:

- [ ] **Project 1:** PHP Calculator
- [ ] **Project 2:** Student Grade Management System
- [ ] **Project 3:** Login and Registration System
- [ ] **Project 4:** Inventory Management System
- [ ] **Project 5:** Student Management CRUD System
- [ ] **Project 6:** Simple E-Commerce Website
- [ ] **Project 7:** PHP REST API
- [ ] **Project 8:** Full-Stack PHP + MySQL Web Application

## Final Learning Tasks
- [ ] Read and understand existing PHP code without copying it.
- [ ] Debug PHP errors independently.
- [ ] Use PHP documentation when encountering unfamiliar functions.
- [ ] Practice writing PHP code without tutorials.
- [ ] Refactor old projects to improve code organization.
- [ ] Upload your PHP projects to GitHub.
- [ ] Write README files explaining each project.
- [ ] Build one original PHP project from scratch.
- [ ] Review PHP fundamentals regularly.
- [ ] Learn a PHP framework such as Laravel after becoming comfortable with core PHP.
